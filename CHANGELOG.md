# Changelog

All notable changes to the **CapyStars** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- **Timely Activity Tracking**:
  - Daily, weekly, and monthly goal tracking and completion analytics.
  - Weekly dashboard with 7-day visual activity breakdown and week-over-week navigation.
  - Monthly overview calendar heatmap and routine distribution.
  - Daily/Weekly/Monthly achievements and celebratory milestone badges.
- **Weekday vs. Weekend Scheduling**:
  - Smart chore scheduling for everyday, weekday-only (Mon–Fri), and weekend-only (Sat–Sun) tasks.
  - Automatic filtering on child dashboard for today's active schedule with toggle to preview all days.
  - Parent schedule manager with weekday vs. weekend filters.
- **Parent Activity & Reports**:
  - Deep weekly/monthly completion rate analytics and audit log.
  - Customizable daily, weekly, and monthly goal targets.
- **Changelog**:
  - Created `CHANGELOG.md` for project version tracking.

## [1.1.0] - 2026-08-16

### Added
- GitHub Gist cloud synchronization for seamless cross-device synchronization between Parent and Child devices.
- Auto-sync on startup and sync status indicator in navigation header.

## [1.0.0] - 2026-08-15

### Added
- Initial release of **CapyStars**: 100% offline-capable PWA for kids chore tracking and rewards.
- Routine groupings: Morning, Afternoon, Bedtime, and Bonus Quests.
- Virtual Pet Companion with happiness levels, growth, feeding mechanics, and pet sanctuary.
- Rewards Shop with star currency redemptions.
- Parent Command Center with 4-digit PIN lock, chore/reward managers, star ledger, and JSON backup/restore.
